# 🍼 수유 앱

시계와 젖병을 눌러 수유량을 기록하는 아이폰 홈 화면용 PWA입니다.
기록은 이 기기의 `localStorage`에만 저장되고 서버로 보내지 않습니다.

- 앱 주소: **https://bswjys.github.io/baby-feeding/**
- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 전체 화면으로 실행됩니다.

## 화면과 사용법

| 번호 | 요소 | 동작 |
| --- | --- | --- |
| ① | 동그란 시계 | 지금 시각을 부드럽게 보여 줍니다. **누르면 ② 시간이 현재 시각(10분 단위)으로 맞춰집니다.** |
| ② | 시간 박스 | 기록에 쓰일 시각 (오전/오후 표시) |
| ③ | 시계 옆 ▲▼ | ②의 시각을 **10분 단위**로 앞뒤 조절 |
| ④ | 기본량 박스 | 한 번 누를 때마다 **+10ml** (60 → 70 → 80 …). 옆의 `−`로 10ml 줄이기, **길게 누르면 60ml로 초기화**. 최대 300ml |
| ⑤ | 젖병 그림 | **누르면 기본량으로 바로 기록** (② 시각 사용). 우유 채움도가 기본량에 맞춰 움직입니다 |
| ⑥ | 젖병 옆 ▲▼ | **이번 수유량(⑦)만** 10ml 단위로 조절 (④ 기본량은 그대로) |
| ⑦ | 수유량 박스 | ⑥으로 맞춘 값. **누르면 이 수유량으로 바로 기록** |
| ⑧ | 기록 박스 | 날짜 · 시간 · 수유량 · 누적(그날의 누적). 행을 누르면 수정, `×`로 삭제(되돌리기 가능) |
| ⑨ | 주간 누적 | 일~토 7칸에 요일별 합계, 오늘 강조, ◀ ▶로 주 이동, 주간 총합 표시 |

- ④ 기본량 변경 시 ⑦ 수유량도 함께 따라갑니다(⑦을 ⑥으로 따로 만지기 전까지).
- 자정을 넘겨 기록할 때를 위해, ② 시각이 지금보다 1시간 이상 앞서면 **어제 기록**으로 저장됩니다.

## 백업 / 복원

- **백업**: 기록과 기본량을 `수유기록-YYYY-MM-DD.json` 파일로 저장
- **복원**: 백업 파일을 골라 현재 기록을 대체 (확인창에서 승인)
- **초기화**: 모든 기록 삭제 + 기본량 60ml

## 파일 구성

```
index.html              화면 구조 (①~⑨, 수정 시트)
styles.css              파스텔 테마 · 모바일 퍼스트 스타일
app.js                  기록/누적/주간 계산 · localStorage · 시계 · 백업
manifest.webmanifest    PWA 매니페스트
sw.js                   오프라인 캐시 (앱 셸 캐시 우선)
icon.svg                아이콘 원본
icon-192.png icon-512.png icon-maskable-512.png apple-touch-icon.png
```

## 로컬에서 실행

```bash
python3 -m http.server 8765
# http://127.0.0.1:8765 접속
```

서비스워커와 매니페스트는 `https` 또는 `localhost`에서만 동작합니다. 파일을 수정해 배포하면 `sw.js`의
`CACHE` 이름(`baby-feeding-v1`)을 올려 주세요. 그래야 홈 화면 앱이 새 파일을 받아 갑니다.
